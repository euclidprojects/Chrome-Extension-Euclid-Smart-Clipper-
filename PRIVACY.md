# Euclid Smart Clipper — Privacy Policy

**Effective Date:** July 2026  
**Publisher:** Euclid Projects

Euclid Smart Clipper is committed to protecting user privacy and data security.

## 1. Information Collection and Usage
- **Web Content & Clips:** Euclid Smart Clipper extracts webpage content, articles, URLs, images, screenshots, and annotations only when triggered explicitly by the user (e.g. clicking "Save to Euclid Smart Notes").
- **Authentication Data:** Euclid ID credentials (such as Google Sign-In UID and email) are processed via Firebase Authentication to synchronize content with your personal Euclid Smart Notes account.
- **Local Storage:** All clipped data is saved locally on your device via IndexedDB prior to synchronization.

## 2. Data Protection
- User content is stored securely in Cloud Firestore and Firebase Storage under strict access rules.
- Browsing history is **never** collected or uploaded.
- Data is **never** sold or shared with third parties.

## 3. User Controls
- Users can choose **Local-Only Mode** to prevent cloud synchronization.
- Data export tools allow downloading all saved content in JSON or Markdown formats.
- Deleting notes removes them from both local storage and cloud database.
